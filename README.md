# 蔚来车型图鉴

响应式交互式产品科普网页，采用 Vite、React 和 TypeScript。无后端、无用户追踪，也没有预约试驾或留资入口。

在线图鉴：<https://vigilwu1.github.io/nio-product-atlas/>（GitHub Pages首次部署完成后可访问）

## 运行

```bash
npm install
npm run dev
```

生产构建：`npm run build`。本项目按工作区中已有车型资料搭建，车型和价格数据的当前核实基线为 **2026-10-15**。

## 当前功能

- 车型分类、搜索、车型详情与最多三款并排对比。
- ES8五座/六座/七座切换；ES9通道/中岛切换；版本价格表与来源链接。
- 外观和座舱信息视图、可拖动的轻量倾斜交互、热点细节卡。
- 价格、BaaS和当期权益分开说明；未核实的条款不填入推测值。
- 键盘快捷键 `⌘K` / `Ctrl+K` 打开车型搜索，`Esc` 关闭详情或对比。
- 对偏好减少动效的用户关闭动画；移动端支持触控与窄屏布局。

## 资料边界

- 官方产品页与配置表访问日期及链接保存在车型数据中。当前价格显示为该日配置表列价，不保证等于今天的实时可下定价格。
- ET7、EC7当前资料表为2024款且在售状态未核实，因此被放在折叠的“其他车型资料”中，不计入在售筛选或三车对比。
- 当前工作区只有ET5、ES8、ES9三张官方外观单图。其他车型使用明确标注的轮廓示意；官方多角度、座舱图组和真实3D资产仍需补充。
- 现阶段“拖动”只产生轻量倾斜预览，不会伪装成真实360°旋转或实车3D。交互点展示可定位的车型资料。
- 价格、BaaS月费、活动权益和销售状态在对外发布前应重新核对官方配置器及条款。图像来源记录在 `public/media-sources.json`。

## 目录

- `src/data/models.ts`：车型、版本、参数、差异说明与来源数据。
- `src/App.tsx`：车型目录、交互详情、热点和对比视图。
- `src/styles.css`：桌面与移动端布局及交互样式。
- `public/media-sources.json`：本地官方图片的来源与缺口清单。

## 持续更新

车型、价格、权益和销售状态有变动时，先更新 `src/data/models.ts` 与来源核对日期，再替换或补充 `public/images/` 中获准使用的素材，并同步 `public/media-sources.json`。推送到 `main` 后，GitHub Actions 自动重新构建并发布到 Pages。
